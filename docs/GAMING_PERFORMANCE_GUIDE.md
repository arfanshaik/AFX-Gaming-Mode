# AFX Gaming Performance Guide

## Before gaming

- Keep GPU drivers updated from official vendor sources.
- Keep enough free SSD space.
- Use your laptop manufacturer's performance mode if appropriate.
- Plug in the charger when gaming on a laptop.
- Keep temperatures under control.
- Match the game's FPS cap to your display and hardware.
- Close apps you personally know you do not need.

## What AFX Gaming Mode changes

AFX Gaming Mode can:

- raise the selected game process priority
- switch Windows to the High Performance power plan
- monitor CPU/RAM usage
- show resource-heavy background processes
- restore the Balanced power plan after the game exits

## Why it does not auto-kill apps

Automatically terminating background processes can close unsaved work, break launchers, or interfere with anti-cheat and game services.

AFX Gaming Mode shows heavy processes instead so you can decide what to close.

## FPS expectations

Performance gains vary by PC. CPU/GPU limits, thermals, game engines, graphics settings, drivers, and background load all matter.
